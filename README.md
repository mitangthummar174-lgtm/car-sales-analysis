# 🚗 Car Sales Analysis Dashboard | Power BI

## 📌 Project Overview
This project presents an interactive Car Sales Dashboard built using Microsoft Power BI to analyze sales performance and visualize key business insights.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📊 Dashboard Features
- Sales performance analysis
- Interactive charts and visualizations
- Key performance indicators (KPIs)
- Data-driven business insights

## 📁 Project Files
- `car sales.pbix` — Power BI dashboard file
- `screenshots/` — Dashboard preview images (optional)

## 🚀 How to View
1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the report and interact with the available filters.
